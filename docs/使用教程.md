# 使用教程

从零到能在手表上开车门，按顺序做一遍即可。全程只需要手机和手表，不需要电脑。

---

## 0. 准备

| 项目 | 要求 |
| --- | --- |
| 手机 | Android 8.0 及以上 |
| 账号 | 能登录「奇瑞汽车」官方 App 的手机号，且车辆已开通车联网 |
| 手表 | 支持快应用的小米手表（Vela 系统），已与小米运动健康配对 |
| 其他 | 手机需安装「小米运动健康」；手表侧安装需 AstroBox |

---

## 1. 安装手机端

1. 下载 [CheryLinker-1.0.0.apk](https://github.com/你的仓库/releases)（或仓库内 `dist/CheryLinker-1.0.0.apk`）；
2. 传到手机后点开安装，提示「未知来源」时允许一次；
3. 桌面出现「Chery Linker」图标，打开。

## 2. 登录

1. 输入 11 位手机号，点「获取验证码」；
2. 收到短信后填入，点「登录」；
3. App 会自动完成：登录 → 拉取车辆列表 → 选中默认车辆 → 换取车辆凭证 → 读取车况。全程约 2~5 秒，直接进首页。

**验证码发不出去？** 奇瑞限制每个号码 1 小时最多 3 条。显示「发送过于频繁」就等一会儿；之前已收到的验证码依然可用，不必重发。

**登录成功但没看到车？** 说明该账号下没有车辆，或车辆未开通车联网。可在设置里手动填写 VIN。

登录态会保存在本机。以后打开 App 直接进首页；如果车辆凭证过期，App 会用已保存的账号凭证自动重新绑定，**不会**再要求你发短信。只有退出登录或换账号时才需要重新登录。

## 3. 首页能做什么

- **车况卡片**：车名、锁状态、剩余续航、电量，以及「解锁 / 上锁 / 开后备箱 / 关后备箱」四个按钮；
- **胎压与温度**：四轮胎压、车内温度；
- **快捷操作**：空调、鸣笛寻车、车窗通风等。部分功能云端未对所有车型开放，点了会提示「云端暂无开放接口」；
- **详情**：总里程、车辆识别信息等；
- 顶部右侧齿轮 = 设置（配色、手动凭据、退出登录）。

点按钮后状态不会立刻变，车控是异步下发：云端返回「已下发」后，等 10~30 秒再点刷新查看实际状态。**关后备箱使用 `controlType=2`，已实车验证可用。**

## 4. 添加桌面小组件

1. 先用 App 成功读取一次车况；
2. 回到桌面长按空白处 → 「小组件」；
3. 找到「Chery Linker 车辆状态」或「Chery Linker 续航」拖到桌面；
4. 组件每 30 分钟自动刷新，也可以点组件上的刷新按钮。

## 5. 安装手表端

手表端不是独立联网的，它通过蓝牙把请求交给手机 App 处理，所以手机上必须装本 App 并保持运行。

1. 手机装 **AstroBox**，按提示取 AuthKey（小米运动健康 → 我的 → 关于 → 连点图标 10 次 → 用表盘自定义工具的「AuthKey 读取」）；
2. 手表：设置 → 系统操作 → 连接新手机；
3. AstroBox 连上手表后，**先删除旧的「车控」**，再安装 `dist/CheryLinker-Watch-2.5.3.rpk`；
4. 手表上打开「车控」，第一页状态点由灰变绿即连通。

### 硬性前提（不满足会直接拒收）

- 手表端包名必须与手机 App 相同：`com.chery.vehicontrol`；
- 手表端必须用与手机 APK **相同的证书**签名。

发行包已经处理好这两点。自己重新打包时若换了签名，需要把新证书同步给手表端重新出包。

### 让连接稳定

- 手机端 App 关闭电池优化 / 允许后台运行，否则进程被杀手表会掉线；
- 小米运动健康必须保持与手表连接；
- 手表端「诊断」页会显示链路状态、上次错误码、包名和访问密码，排查时先看这一页。

## 6. 手表手势

手表支持 6 种手势：攥拳、捏合、顺时针、逆时针、推、拉。默认只有「攥拳 → 开后备箱」，其余为不执行。

在手机 App 首页下方的手势卡片里，可以给每个手势单独指定动作（解锁 / 上锁 / 开后备箱 / 关后备箱 等）。改完立即生效，不用重启手表。

出于安全考虑，解锁类动作在手表上仍需二次确认；不想让手表解锁，可在设置里关掉「允许手表解锁」。

## 7. 常见问题

| 现象 | 处理 |
| --- | --- |
| 提示「验证码发送过于频繁」 | 1 小时 3 条限制，等待；旧验证码仍可用 |
| 提示「验证码错误或已过期」 | 重新获取，5 分钟内输入 |
| 登录成功但车况为空 | 车辆休眠/未开通车联网；先启动车辆或稍后刷新 |
| 车控提示已下发但车没反应 | 云端只保证下发，车辆未唤醒时不执行；靠近车再试一次 |
| 手表显示「密码不对」 | 两端包名/签名不一致，或装了不同版本的 rpk |
| 手表「未连接」/ 无应答 | 手机 App 被后台杀掉；关闭电池优化后重开 App |
| 重新安装 APK 后手表不通 | 签名变了，需用同签名重新给手表出包 |
| 换账号 | 设置 → 退出登录，回到登录页重新输入手机号 |

## 8. 卸载与清理

设置 → 退出登录会清空本机的账号 token、车辆 token 和缓存。直接卸载 App 也会一并删除这些数据，不会留在云端或其他地方。
